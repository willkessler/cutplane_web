# Original resources

Copied unchanged from the original C implementation (`cutplane_Sequoia`, MIT licence, see
[`LICENSE`](LICENSE)):

- `rsc/`: tools, plates, pads, decals (`.dcl`), colours (`cpcolors.rsc`) and other resources.
- `icons/`: tool icons, in `.cut` format.
- `cpl/`: the CPL source for every object behaviour.
